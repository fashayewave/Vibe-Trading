## Decision 003

**Topic:** Primary Analytical Framework

## Decision 004

**Topic:** Evidence Standard

**Decision:** No indicator enters HQATL because it is popular. It enters because it has evidence, complements the framework, and survives testing.

**Status:** `LOCKED`

---

## Decision 005

**Topic:** Development Workflow

**Decision:** Vision → Roadmap → Decision Log → Feature Audit → Research Library → Specifications → Implementation → Testing → Validation.

**Status:** `LOCKED`

---

## Decision 006

**Topic:** Specification Gatekeeping Workflow

**Decision:** Research Library → Research Review Queue → Evidence Review → Verified Evidence Library → Research Specification → Architecture Design → Engineering Specification → Implementation → Testing → Validation → Production Candidate. No research claim may influence an HQATL specification before evidence review. No implementation may begin without the required approved research specification, architecture design, and engineering specification. Passing tests does not replace empirical validation.

**Status:** `LOCKED`
